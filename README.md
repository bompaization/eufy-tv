# Eufy TV

An unofficial Android TV viewer for Eufy Security cameras, made by Erik Lenaerts.

This page only hosts the downloads. Open **Releases** on the right and download the newest `eufy-tv.apk`.

## What you need

- An Android TV or streaming box running Android 8.0 or newer. Both 64-bit and 32-bit devices work.
- A reasonably powerful device. Your cameras send sharp 4K video, so weaker devices may freeze or show black pictures when several cameras play together. The Nvidia Shield Pro handles it fine.
- A Eufy account with your cameras. A separate account for this app is not strictly needed, but I recommend it.
- You need to know how to sideload an app to your Android TV device.

## Good to know

- I've only tested it with cameras connected to a HomeBase and recording to local storage. Other setups may not work.
- The events list only shows recordings saved locally, on the HomeBase or the camera's memory card. Cloud-only recordings won't appear.
- The app checks this page for new versions and offers to update itself.
- It uses an unofficial, open-source library, so Eufy changes could break it.
